# Campus Transit — Joy University

Responsive digital timetable prototype based on the supplied Joy University transport-board photograph.

## Features
- Bus timetable transcription
- Train departures for Kanyakumari (CAP) and Nagercoil (NCJ)
- Search and bus/train filters
- Responsive mobile layout
- Source/provenance notice
- Research direction toward GTFS Schedule and GTFS Realtime

The displayed timetable is a transcription of the supplied photograph, not a live operational feed. Verify timings with the university/operator before travel.

## Research
GTFS Schedule provides a standard model for agencies, routes, stops, trips and stop times. GTFS Realtime supports trip updates, service alerts and vehicle positions. A production campus system can replace the static dataset with an authoritative operator feed.
